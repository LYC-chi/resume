发布通过 GitHub REST API 完成。仅凭账号邮箱无法调用 API，需要使用该账号下的 Personal Access Token 授权；Token 只保存在你的浏览器本地，不会上传到任何第三方。
Token 怎么获取？（30 秒）
  1. 打开 github.com/settings/tokens/new
  2. Note 随便填，例如 Resume Studio
  3. Expiration 选一个有效期（建议 90 天）
  4. 勾选 repo 权限（含公开/私有仓库读写）
  5. 点 Generate token，复制 ghp_ 开头的一串字符，粘贴到上方输入框

仓库不存在时，发布流程会自动帮你创建（公开仓库才能免费开启 GitHub Pages）。
